# 自审清单 30 项（写完代码 / review 前逐条过）

> 用法：每项标 ✅ / ❌ / N/A。❌ 必须改或写"为什么不改"。
> 30 秒能过的项不要跳过——跳过项就是线上事故的候选。

## 一、接口与契约（1–6）

- [ ] 1. 公共函数有 Doxygen 英文头注释：核心作用、每个参数的 NULL 契约与所有权、返回值/错误码、调用上下文（可阻塞？可持锁？信号处理函数可用？）
- [ ] 2. 公开函数原型有 `(void)`（无参）、`const`（不改的入参）、长度参数（指针 + 长度成对）
- [ ] 3. 返回错误码与模块既有风格一致（`0` / 负 `errno`，不混用 `-1` + errno）
- [ ] 4. 结构体字段用定长类型；跨边界结构体无 `size_t`、无裸 `int/long`、无指针
- [ ] 5. 头文件自足、有 guard、无变量定义、无 `static` 函数
- [ ] 6. 新增的枚举/宏/常量已具名，无魔术数字

## 二、内存与资源（7–14）

- [ ] 7. 每个 `malloc/calloc/realloc` 都判空；失败路径回滚**全部**已分配（循环分配尤其注意）
- [ ] 8. `realloc` 用临时变量接收
- [ ] 9. `free` 后置 NULL；结构体指针字段同步清空
- [ ] 10. 所有 fd / socket / 文件 / 线程句柄在每条返回路径上关闭或 join；关闭前已从事件注册表/`fd_set` 摘除
- [ ] 11. 释放顺序与获取顺序相反（`out:` 标签内）
- [ ] 12. 无 `alloca`、无 >4KB 栈缓冲
- [ ] 13. 拷贝前同时检查 `src` 实际长度与 `dst` 容量；`snprintf` 截断已处理
- [ ] 14. 无 `strcpy/strcat/sprintf`；`memcpy` 长度来自本地校验后的值；`sscanf` 格式符与目标类型宽度匹配

## 三、并发与上下文（15–20）

- [ ] 15. 新增共享数据已注明由哪把锁保护
- [ ] 16. 持锁期间无 IO / 回调 / `malloc` / `sleep`
- [ ] 17. 涉及两把锁时，顺序符合全局锁序
- [ ] 18. 条件变量在 `while` 中等待；超时用 `CLOCK_MONOTONIC`
- [ ] 19. 信号处理函数只碰 `volatile sig_atomic_t` 与 async-signal-safe 调用
- [ ] 20. 线程创建/退出路径明确：谁创建、谁 join、取消如何处理；栈大小按 `RLIMIT_STACK` **显式**设置（不依赖 libc 默认）

## 四、错误路径与日志（21–26）

- [ ] 21. 每个可能失败的调用都有失败分支（或 `(void)` + 理由）
- [ ] 22. 错误码可区分（`EINVAL/ENOMEM/EAGAIN/ETIMEDOUT`），不是一律 `-1`
- [ ] 23. 部分失败已回滚（半初始化状态不会留在表里/链表里）
- [ ] 24. 日志走封装宏 `dbg_printf`（无裸 `printf/fprintf`）；级别正确；热路径无 `ERROR` 洪泛（有限速）
- [ ] 25. 格式串与参数类型匹配（`%zu`、`PRIu64`、`%p`、NULL 字符串）
- [ ] 26. 日志不含秘钥/完整报文；路径已脱敏

## 五、可移植性与性能（27–30）

- [ ] 27. 无未定义行为：无有符号溢出、无越界、无未对齐访问、无 UAF
- [ ] 28. 端序转换齐全；`packed` 结构体成员用 `memcpy` 访问
- [ ] 29. 无隐式窄化转换；有符号/无符号比较已统一
- [ ] 30. 热路径无新增 syscall / 无重复分配 / 无每包 `printf`

## 编译与交付

- [ ] `-Wall -Wextra -Werror`（加 profile 开关）0 warning
- [ ] 格式改动与逻辑改动分开（两个 diff）
- [ ] 若改了公共接口：调用方全部更新，头注释同步
- [ ] 新增/修改的行为有最小验证方式（单测、脚本、抓包、日志）
