# 访谈问题库（按主题）

> 用法：每个主题挑 8–10 题，**一次最多问 5 题**。顺序：经历过什么 → 怎么判断 → 默认值 → 何时反向。
> 提问原则：问**具体事件**，不问抽象偏好（"你一般怎么做"最容易得到正确的废话）。

## 通用四类问法（任何主题都能套）

1. **事件**：最近一次因为这个主题出问题是什么场景？现象是什么？
2. **判断**：当时你怎么区分"是 A 还是 B"？看了哪些证据？
3. **默认**：如果没有特殊要求，你的默认选择是什么？为什么？
4. **反向**：什么情况下你会故意不这么做？代价是什么？

## Socket

1. 你写服务端时，第一版会先设哪些 socket 选项？有没有"忘设就出事"的清单？
2. 收包时你怎么界定一条消息？长度前缀、分隔符还是定长？为什么？
3. 对端半开（拔网线/断电）你怎么发现？心跳间隔和超时怎么定？
4. 非阻塞下 `send` 只写了一半，你的处理路径是什么？
5. 连接数上万时，你的线程模型是什么？为什么不是每连接一线程？
6. 你遇到过最诡异的连接问题是什么？（TIME_WAIT / fd 复用 / 惊群 / 粘包）
7. 你的超时用 `SO_RCVTIMEO`、`poll` 还是应用层时间轮？为什么？
8. 关闭连接时，你怎么保证数据不丢、fd 不复用？
9. 你怎么观测"连接健康"？看哪些计数器？
10. 什么时候你会选 UDP 而不是 TCP？上面的可靠性怎么补？

## 内存

1. 你模块的内存是启动期分配还是运行期分配？为什么？
2. 对象数量有上限吗？上限怎么估的？估小了怎么办？
3. 你用池还是 malloc？池的块大小怎么定？耗尽时怎么办？
4. 结构体里含指针时，你怎么表达所有权？有没有 `_clone/_free` 约定？
5. 你怎么发现内存泄漏？线上和开发期分别用什么手段？
6. 遇到过碎片问题吗？怎么缓解的？
7. 大缓冲放栈还是堆？栈大小怎么定？
8. 什么时候你会用 arena/一次性分配？

## 数据结构

1. 你选哈希还是树？判据是什么（数量、读写比、是否需要有序）？
2. 表项数量级一般多少？小表你也用哈希吗？
3. 遍历时删除你怎么做？
4. 你关注 cache 局部性吗？有没有为此改过布局（AoS/SoA）？
5. 定时器/超时你怎么组织？最小堆、时间轮还是有序链表？
6. 你用过无锁结构吗？什么场景？踩过什么坑？

## 性能

1. 你接到"性能优化"需求时，第一步做什么？
2. 你的延迟预算一般定多少？P99 还是均值？
3. 你怎么定位热点？perf / 打点 / 二分？
4. 你做过收益最大的优化是什么？收益多少？
5. 什么情况下你会拒绝一个优化请求？
6. 你怎么防止性能回归？

## 并发

1. 你的线程模型怎么选？单线程事件循环还是线程池？
2. 共享数据怎么保护？锁的粒度多大？
3. 你怎么定锁顺序？有没有文档？
4. 遇到过死锁吗？怎么定位的？
5. 什么时候用原子、什么时候用锁？
6. 线程怎么优雅退出？用过 `pthread_cancel` 吗？

## 错误处理与日志

1. 错误码怎么设计？调用方怎么用？
2. 什么级别打什么日志？热路径怎么限速？
3. 线上排障你最先看什么？
4. 有没有"日志打太多把系统拖垮"的经历？

## 构建与工具

1. 编译开关有哪些？`-Werror` 是全量还是新代码？
2. 静态检查/格式化工具用哪些？
3. CI 跑什么？单测覆盖率要求？

## 收尾追问（每个主题结束时问）

- 这条规则有反例吗？什么情况下不适用？
- 如果团队新人只记一句话，你希望是哪句？
- 这条要进 Skill（每次遵守）还是只做经验记录（供检索）？
